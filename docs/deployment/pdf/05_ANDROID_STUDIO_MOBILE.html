my boss app — Android Studio & Mobile App Run Guide

Audience: Developers, QA

Purpose: Run the Flutter employee app and connect it to the backend

1. Prerequisites

ToolVersion
Android StudioLatest stable
Flutter SDK3.35.7 / Dart 3.9.2 (FVM — see myboss-mobile/.fvmrc)
BackendRunning (see 02_RUN_DEMO_SERVER.md)

Verify Flutter:

fvm flutter doctor

2. Open project in Android Studio

  1. Launch Android Studio
  1. File → Open
  1. Select folder: myboss-mobile
  1. Wait for Gradle sync to finish
  1. If prompted: Trust Project

3. Start Android Emulator

  1. Tools → Device Manager
  1. Create device (if none): Pixel 6, API 34 recommended
  1. Click ▶ Play to start emulator
  1. In Android Studio toolbar, select the emulator as run target

4. Start backend (required before mobile)

Option A — Docker (demo / infra):

cd myboss-platform
./scripts/deploy-demo-server.sh 127.0.0.1
./scripts/verify-mobile-api.sh 127.0.0.1 --gateway

Option B — Local dev (no Docker):

cd myboss-backend
npm run start:dev

5. Run mobile app

Terminal (or Android Studio Run ▶ button):

cd myboss-mobile
fvm flutter pub get
fvm flutter gen-l10n
fvm flutter run --dart-define=DEMO_MODE=true

Or in Android Studio: select main.dart → click green Run button (add --dart-define=DEMO_MODE=true in Run Configuration).

6. API host modes

ModeCommandBackend path
Demo (recommended)--dart-define=DEMO_MODE=trueGateway :8090 (probed at startup)
Dev emulator--dart-define=ENV=developmentDirect ports 3001–3005 via 10.0.2.2
Dev physical--dart-define=API_HOST=<lan-ip>Direct ports 3001–3005

When DEMO_MODE=true, the app probes GATEWAY_ORIGIN and API_HOSTS and picks the first reachable /health.

Emulator with demo gateway:

fvm flutter run --dart-define=DEMO_MODE=true --dart-define=GATEWAY_ORIGIN=http://10.0.2.2:8090

7. Physical Android device

Demo APK (recommended for QA / external devices)

cd myboss-mobile
./build-local-android.sh
# Output: build/android-dist/myboss-demo-<lan-ip>.apk

Copy APK to phone, uninstall old app first, then install.

Requirements:

  • Phone and Mac on same Wi‑Fi or Cloudflare tunnel running
  • Demo gateway on port 8090

Development run (direct microservice ports)

  1. Find your computer IP:
ipconfig getifaddr en0    # macOS example: 10.6.208.129
  1. Run:
fvm flutter run --dart-define=ENV=development --dart-define=API_HOST=<lan-ip>
  1. Phone and laptop must be on the same Wi‑Fi. Allow firewall access to ports 3001–3005 (dev) or 8090 (demo).

10. Common issues

ProblemFix
Network error on loginBackend not running; check curl http://127.0.0.1:8090/health
Emulator cannot reach APIUse GATEWAY_ORIGIN=http://10.0.2.2:8090 with DEMO_MODE=true
Physical device failsSame Wi‑Fi; test http://<mac-ip>:8090/health in phone browser
Old APK still failsUninstall app before installing new APK
Gradle sync failedFile → Invalidate Caches; fvm flutter clean && fvm flutter pub get
OTP not receivedCheck auth logs for [DEMO OTP]; use demo build with auto-fill
