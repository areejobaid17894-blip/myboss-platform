my boss app — DevOps & Infrastructure Installation Guide (Docker)

Audience: DevOps / Infrastructure team

Environment: Demo server (1-week event, ~1,500 users/day)

Deploy method: Docker Compose

1. Overview

Backend runs as 5 Docker containers built from docker/Dockerfile.*.

DockerfileServicePortApigee prefix
Dockerfile.authauth-service3001/auth/api/v1
Dockerfile.useruser-service3002/user/api/v1
Dockerfile.configconfig-service3003/config/api/v1
Dockerfile.squadsquad-service3004/squad/api/v1
Dockerfile.surveysurvey-service3005/survey/api/v1

Optional: Dockerfile.admin-portal → port 8081 (direct) or gateway 8090/login

Compose file: docker/docker-compose.demo.yml

3. Install Docker (one time)

curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER
# Log out and back in
docker --version
docker compose version

Or use the repo script:

git clone <repository-url> /opt/myboss/myboss-platform
cd /opt/myboss/myboss-platform
chmod +x scripts/*.sh
./scripts/install-demo-server.sh

4. Environment file

cd /opt/myboss/myboss-platform
cp .env.example .env
nano .env

Required:

NODE_ENV=demo
APP_ENV=demo
JWT_SECRET=<openssl rand -base64 48>
TWO_FA_DEMO_ENABLED=true
CHAT_ENABLED=true
TAWK_PROPERTY_ID=your_tawk_property_id
TAWK_WIDGET_ID=default

5. Build and start (Docker Compose)

cd /opt/myboss/myboss-platform
./scripts/start-demo-server.sh

This runs:

docker compose -f docker/docker-compose.demo.yml up -d --build

With admin portal:

docker compose -f docker/docker-compose.demo.yml \
  --profile with-admin up -d --build

Admin UI: http://demo-server:8090/login (gateway) or http://demo-server:8081 (direct)

6. Verify

./scripts/verify-backend.sh
docker compose -f docker/docker-compose.demo.yml ps
docker compose -f docker/docker-compose.demo.yml logs -f auth-service

7. Firewall

sudo ufw allow OpenSSH
sudo ufw allow from <APIGEE_IP_RANGE> to any port 3001:3005 proto tcp
sudo ufw enable

8. Stop / update

# Stop
./scripts/stop-demo-server.sh

# Update after git pull
git pull
./scripts/start-demo-server.sh
